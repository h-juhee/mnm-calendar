# 병원 로고 폴더

피그마에서 개별로 내보낸 병원 로고 파일을 이 폴더에 넣어 주세요.

- 권장 형식: 투명 배경의 SVG 또는 PNG
- 권장 파일명: 병원명과 동일한 한글 이름 (예: `연세이로운치과.svg`)
- 같은 병원에 PNG와 SVG를 동시에 넣지 마세요.
- 파일명 앞뒤의 공백과 `\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `|` 문자는 사용하지 마세요.

추후 병원명·원장명 자동 매칭 기능에서 이 폴더의 파일을 사용합니다.

새 파일을 추가한 뒤에는 `src/utils/hospitalLogoUtils.ts`의
`HOSPITAL_LOGO_FILES` 목록에도 파일명을 추가해야 자동 매칭됩니다.
