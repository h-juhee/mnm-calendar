# MNN Calendar

병원의 월간 진료 일정을 이미지로 제작하는 React 기반 웹 애플리케이션입니다. 병원 정보와 진료 일정을 입력하고, 원하는 템플릿과 출력 규격을 선택해 실시간으로 결과를 확인할 수 있습니다. 완성된 일정표는 PNG로 내려받거나 맞춤 디자인 요청과 함께 Notion으로 전송할 수 있습니다.

## 주요 기능

### 일정 설정

- 병원명, 원장명, 대표 색상, 로고 등록
- 연도와 월 선택
- 달력 요일 표기 방식 선택: 한국어, 영어, 한자, 일본어
- 매주 반복되는 정기 휴진 요일 설정
- 휴가 시작일과 종료일을 이용한 연속 휴진 설정
- 달력의 날짜를 클릭해 개별 일정 지정
  - 휴진
  - 오전 진료
  - 오후 진료
  - 세미나·휴진
  - 단축 진료 및 시작·종료 시간
  - 야간 진료
  - 토요일 진료
  - 정상 진료
  - 직접 입력
- 날짜별 일정 라벨 색상 지정
- 요일별 진료시간, 점심시간, 안내 문구 설정

개별 날짜 설정은 휴가 기간이나 정기 휴진보다 우선 적용됩니다. 우선순위는 다음과 같습니다.

1. 날짜별 개별 일정
2. 휴가 기간
3. 정기 휴진 요일
4. 정상 진료

### 디자인 편집

- 기본 템플릿 4종 제공
- 제목 스타일과 글꼴 변경
- 사용자 배경 이미지 업로드: PNG, JPG, WEBP, 최대 10MB
- 제목, 부제목, 병원 정보, 진료시간, 달력 요소 편집
- 요소 드래그 이동 및 크기 조절
- 텍스트, 글자 크기, 글자 색상 변경
- 전체 설정 초기화
- 변경 사항 실시간 미리보기

### 이미지 출력

다음 규격으로 PNG 이미지를 생성합니다.

| 규격 | 해상도 |
| --- | ---: |
| 정사각형 | 1080 × 1080 |
| A4 세로 | 2480 × 3508 (210 × 297mm, 300dpi 기준) |
| A4 가로 | 3508 × 2480 (297 × 210mm, 300dpi 기준) |
| DID 가로 | 3840 × 2160 |
| DID 세로 | 2160 × 3840 |

### 데이터 저장 및 맞춤 디자인 요청

- 병원 정보와 월별 작업 내용을 브라우저에 자동 저장
- 마지막으로 작업한 월 자동 복원
- 업로드한 배경 이미지는 브라우저의 IndexedDB에 저장
- 현재 일정 이미지와 요청 정보를 Notion 데이터베이스로 전송
- 요청 규격, 필수 포함 내용, 다음 달 이벤트, 디자인 요청사항, 특이사항 입력

> 작업 데이터는 현재 브라우저에 저장됩니다. 다른 브라우저나 기기에는 자동으로 동기화되지 않으며, 브라우저 데이터를 삭제하면 저장 내용도 사라질 수 있습니다.

## 사용 방법

1. 첫 화면에서 병원명, 원장명, 대표 색상을 입력합니다.
2. 사용할 템플릿을 선택합니다.
3. 제작할 연도와 월, 정기 휴진일, 휴가 기간, 진료시간을 설정합니다.
4. 미리보기 달력의 날짜를 클릭해 해당 날짜의 일정을 조정합니다.
5. 배경, 글꼴, 제목 스타일과 각 디자인 요소를 편집합니다.
6. 출력 규격을 선택한 뒤 **이미지 다운로드**로 PNG를 저장합니다.
7. 별도 제작이 필요하면 **맞춤 디자인 요청하기**에서 요청 내용을 작성해 전송합니다.

## 개발 환경

- React 19
- TypeScript 6
- Vite 8
- CSS Modules
- `html-to-image`
- Pretendard
- Vercel Serverless Function
- Notion API

Node.js 20 이상 사용을 권장합니다.

```bash
npm install
npm run dev
```

개발 서버 실행 후 터미널에 표시되는 로컬 주소로 접속합니다.

## 환경 변수

맞춤 디자인 요청을 Notion에 저장하려면 프로젝트 루트에 `.env.local` 파일을 만들고 다음 값을 설정합니다.

```env
VITE_APP_MODE=internal
NOTION_TOKEN=ntn_...
NOTION_DATA_SOURCE_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- `VITE_APP_MODE`: `internal`이면 내부 직원용, `customer`이면 원장님용 앱을 표시합니다. 생략 시 내부용입니다.
- `NOTION_TOKEN`: Notion Internal Integration 시크릿
- `NOTION_DATA_SOURCE_ID`: 연결할 Notion 데이터 소스 ID
- 서버 전용 시크릿이므로 변수명 앞에 `VITE_`를 붙이지 마세요.
- Vercel 배포 시 같은 값을 프로젝트의 Environment Variables에 등록해야 합니다.

데이터베이스 연결과 권한 설정에 관한 자세한 내용은 [Notion 설정 안내](docs/notion-setup.md)를 참고하세요.

Notion 환경 변수가 없거나 API가 배포되지 않은 환경에서는 맞춤 디자인 요청 전송이 실패할 수 있습니다. 일정 편집과 PNG 다운로드는 계속 사용할 수 있습니다.

```text
src/types/            일정, 글꼴, 출력 규격 타입

```
